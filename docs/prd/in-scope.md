# 3. In‑Scope (MVP)
- Classic 3×3 tic‑tac‑toe gameplay with turn order indicator.
- Two modes:
  - Solo vs CPU with simple AI (win/block + basic center/corner heuristics).
  - Local Pass‑and‑Play (two players on one device).
- Win/draw detection and win‑line highlight.
- Quick match flow: New Game/Restart; minimal onboarding tip.
- Local stats: wins/losses/draws per mode; device‑local persistence.
- Lightweight polish: subtle animations, optional haptics and short sound cues.
