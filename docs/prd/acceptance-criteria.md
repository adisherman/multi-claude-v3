# 14. Acceptance Criteria (MVP‑level)
- From Home, users can start Solo or Pass‑and‑Play and complete a match; rematch available within one tap.
- Win/draw detection is correct for all cases; win line is visibly highlighted.
- CPU makes legal moves promptly (<200ms typical) and blocks obvious wins when possible.
- Stats update accurately after each match and persist across restarts.
- Sound/haptics toggles work immediately and persist.
- Basic accessibility checks pass (contrast targets; min 44dp touch targets; sensible focus order).
