# 6. Experience & UI Goals
- Clean, readable visuals with high contrast; large touch targets.
- Motion used sparingly (tile reveal, win‑line) with 60fps target on typical devices.
- Haptics: light feedback on move and end‑state; sounds: click + short win jingle (toggleable).

## 6.1 Core Screens
- Home: mode selection, last results snippet, quick actions.
- Game: board, HUD (turn indicator, restart), end‑state dialog.
- Settings: toggles for sound/haptics; reset stats; credits.
