# 13. Epics (MVP)

## Epic 1: Core Game Engine & UI
- Goal: Implement rules engine, board rendering, turn handling, win/draw detection, and basic UX polish.
- Value: Playable local matches with delightful responsiveness.

## Epic 2: Solo Mode (CPU)
- Goal: Add CPU opponent with basic heuristics and integrate into game flow.
- Value: Single‑player engagement without network.

## Epic 3: Persistence, Settings, and Accessibility Polish
- Goal: AsyncStorage persistence for stats/settings; settings UI; WCAG AA basics; sounds/haptics toggles; QA pass.
- Value: Retained progress, comfort controls, and inclusive experience.
