# 7. Functional Requirements
1) Start a New Game in either mode from Home.
2) Render 3×3 board; tap to place current player’s mark in an empty cell.
3) Switch turns; prevent overwrites; detect win/draw immediately.
4) Solo mode: CPU selects moves using basic heuristics; difficulty tuned for brisk play.
5) On win/draw: present result, play optional feedback, highlight win line, and offer rematch.
6) Persist and display local stats (by mode): wins/losses/draws.
7) Settings toggles persist locally and take effect instantly.
