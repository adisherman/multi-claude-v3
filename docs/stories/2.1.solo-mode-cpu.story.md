# Story 2.1 Solo Mode (CPU)
Status: Approved
Epic: 2 — Solo Mode (CPU)

As a solo player,
I want to play against a CPU opponent,
so that I can enjoy quick single‑player matches without needing another person.

## Acceptance Criteria
1. From Home, I can start a Solo vs CPU match in ≤3 taps.
2. CPU moves are always legal and occur promptly (≤200ms typical on mid‑range devices).
3. CPU prioritizes immediate wins, blocks obvious opponent wins, and prefers center/corners otherwise.
4. Win/draw detection remains correct; win line is highlighted; end‑state dialog offers Rematch and Back to Home.
5. Integration tests cover a representative Solo flow, verifying CPU responses and end states.
6. Accessibility and performance remain consistent with Story 1.1 standards (44dp targets, adequate contrast, 60fps aim).
